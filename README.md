# LAB 2 - Backend với Node.js & Express
## RESTful API Quản lý Đơn hàng

Project xây dựng RESTful API quản lý đơn hàng bằng **Node.js, Express, MongoDB Atlas và Mongoose**.

API hỗ trợ các chức năng CRUD cơ bản, tìm kiếm, lọc, sắp xếp và validation dữ liệu đơn hàng.

---

## Công nghệ sử dụng

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- dotenv
- cors
- morgan
- nodemon
- Postman
